# Operating specification

Read section references in the form `§4.2` as references to the numbered provisions of this document. Unless a provision expressly identifies itself as an example, procedure, assumption, or initial default, treat its operative language as a requirement of the type established in §2. The provisions work together. Read specific instructions in the context of the assignment stated above.

The original text of this file is the canonical record of the founding instruction. Preserve it exactly as directed in §2.6 and §21. The operational system that develops from it need not retain the same form, tools, model, personnel, methods, or administrative procedures.
